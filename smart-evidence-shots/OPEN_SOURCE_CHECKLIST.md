# Release checklist

- [ ] Test video sampling and original-resolution extraction on a non-confidential sample video.
- [ ] Test PDF generation using a synthetic or authorized screenshot folder.
- [ ] Confirm no video, screenshot, manifest, PDF, or user-specific path is staged.
- [ ] Check `SKILL.md` and `references/` for machine-specific commands before release.
- [ ] Confirm the included MIT license is the intended choice.
